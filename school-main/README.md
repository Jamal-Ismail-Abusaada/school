# المدارس الأميرية

صفحة عربية ثابتة تعمل مباشرة بفتح `index.html`، دون تثبيت حزم أو عملية بناء.

## بنية المشروع

- `index.html`: المحتوى، أقسام الصفحة وروابط التنقل.
- `css/stayl.css`: نقطة دخول التنسيقات والمتغيرات والقواعد المشتركة.
- بقية ملفات CSS: تنسيقات مستقلة للتنقل والخدمات والأخبار والإحصاءات والآراء والتواصل والخريطة والتذييل.
- `img/`: الصور الأصلية.
- `js/main.js`: قائمة الهاتف وتمييز القسم الحالي وزر العودة إلى الأعلى، دون مكتبات خارجية.
- `scripts/check.cjs`: فحص بنية HTML والمسارات والروابط الداخلية باستخدام Node.js.

## التحقق

```sh
node scripts/check.cjs
```

## الإصلاحات

- إزالة الوصول إلى `document.body` قبل تحميله، وإزالة اعتماد Bootstrap غير المستخدم ومساره المفقود.
- ضبط العربية واتجاه RTL، وإضافة عنوان للصفحة وأسماء لروابط التواصل ورابط لتجاوز التنقل بلوحة المفاتيح.
- تحويل أزرار التنقل إلى روابط داخلية ذات أهداف موجودة.
- استبدال الإزاحات والارتفاعات الثابتة بتخطيطات Grid وFlex متجاوبة، وتوحيد تنسيقات البطاقات المتكررة.
- إصلاح وحدة `xp` غير الصحيحة وسمات SVG المكررة وإغلاق عنصر `input` غير الصحيح.
- استبدال حقول العرض المعطلة بنصوص عادية، وتحويل مواقيت الدوام من أزرار إلى نصوص.

## التفاعلات

قائمة الهاتف تُفتح بزر «القائمة» وتُغلق عند اختيار قسم أو النقر خارجها أو الضغط على Escape. يتتبع شريط التنقل القسم الحالي أثناء التمرير، ويظهر زر العودة إلى الأعلى بعد تجاوز الواجهة. التنقل سلس ويحترم إعداد تقليل الحركة. عند تعطيل JavaScript تبقى روابط الأقسام ظاهرة وتعمل بشكل طبيعي.

## حدود الوظائف

المحتوى والصور وبيانات التواصل أصلية وتجريبية. لا توجد خدمة خلفية للاشتراك بالبريد؛ استُبدل الحقل غير الموصول بوصف موقع المدرسة. روابط «تعرف أكثر» في الأخبار تقود لقسم التواصل لعدم وجود صفحات تفاصيل. روابط الشبكات الاجتماعية عامة وتحتاج حسابات المدرسة الفعلية قبل النشر.
